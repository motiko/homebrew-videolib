# motiko/homebrew-videolib

Homebrew tap for [VideoLib](https://github.com/motiko/VideoLib) — a Telegram bot that downloads and delivers videos.

## Installation

```bash
brew tap motiko/videolib
brew install videolib
```

## Running as Background Service

```bash
brew services start videolib
```

To manage the service:

```bash
brew services stop videolib
brew services restart videolib
brew services info videolib
```
